Light Stage Manager — Preview Thumbnails
=========================================

This folder stores rendered preview thumbnails (256x256 PNG, one per preset).
Thumbnails are generated by:
  N-panel > LightStageManager > Preview Thumbnails > Render All Previews

The headless Blender process renders Suzanne under each lighting preset
using Cycles. The .render_complete sentinel file is created when done.

Files: <preset_id>.png  (25 files total after first render)
